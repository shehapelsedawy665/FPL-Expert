We have validated the Starting XI formation optimizer against live FPL Team ID 4107702. The next task is to build a proper Bench Order Engine.
Objective
Improve the recommendation for the three outfield bench positions:
1SUB → 2SUB → 3SUB
The substitute goalkeeper must remain separate as Bench GK.
Do NOT change the Starting XI optimizer or the existing Expert Score model in this task.
Core principle
Bench order must NOT simply be the remaining outfield players sorted by Expert Score.
The purpose of bench priority is:
If a starter unexpectedly does not play, which available bench player gives us the best expected FPL replacement value?
Therefore availability / likelihood of actually playing and expected next-GW performance are more important than historical points alone.

Reuse existing calculated signals wherever possible.
Do NOT invent unavailable data.
Do NOT duplicate a factor if it is already incorporated into an existing projection.
Bench Priority V1
Build a deterministic Bench Priority Score for OUTFIELD substitutes.
Its priority hierarchy should be:
Expected availability / expected minutes
Expected performance for the NEXT gameweek
Existing Expert Score as a supporting/tie-breaking signal
Historical form, xG, xA and fixture difficulty should NOT automatically be added again if they are already components of the existing Expert/Future projection.
Avoid arbitrary new weights unless the current scoring architecture already provides justified weights.
If the existing project does not contain a reliable next-GW expected-points metric, clearly report that limitation rather than pretending that one exists.
Availability handling
A high-scoring player with a serious minutes/availability risk should not automatically be 1SUB.
Use the strongest existing availability/minutes information in the project.
Do not hard-code individual player statuses.
FPL formation rules
Preserve official FPL substitution constraints.
A legal XI after substitutions must contain:
exactly 1 goalkeeper
at least 3 defenders
at least 2 midfielders
at least 1 forward
Bench order itself remains 1SUB, 2SUB, 3SUB.
Do not manipulate bench order merely to force every possible substitution to produce a legal formation; FPL auto-substitution rules determine whether a particular bench player can replace a missing starter.
However, the engine should be capable of explaining which bench player would actually enter for example absence scenarios under those rules.
